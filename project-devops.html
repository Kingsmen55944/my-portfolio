Dockerized Multi-Container Web Deployment on AWS EC2

I deployed and hosted two independent websites on a single AWS EC2 instance using Docker.

The project focused on understanding containerization and how multiple applications can be deployed and isolated on the same cloud server. I built and published the application images to my public Docker Hub repositories, then pulled those images directly onto the EC2 instance and deployed them as separate running containers.

What I Implemented

  • Provisioned an AWS EC2 instance to serve as the deployment server.
  • Installed and configured Docker on the EC2 instance.
  • Pulled two application images from my public Docker Hub repositories.
  • Created and ran two separate Docker containers from the images.
  • Deployed both containers on the same EC2 instance.
  • Configured port mapping so each website could be accessed independently:
    • Container 1 → Port 80
    • Container 2 → Port 81
  • Verified that both containerized websites were running successfully at the same time.

Technologies Used

AWS EC2 | Docker | Docker Hub | Linux | Containerization | Port Mapping

Key Learning

This project gave me practical experience deploying containerized applications to a cloud environment. I learned how Docker can package applications into portable containers and how multiple containers can run independently on the same EC2 server while using different ports.

It also strengthened my understanding of the relationship between cloud infrastructure, containerization, application deployment, and networking—key concepts in my journey toward becoming a Cloud/DevOps Engineer.
